KUMA Extended

Модульное расширение для SIEM

Общие

Главный выключатель расширения. Если он выключен, content-скрипты модулей не регистрируются ни на одном домене.

Целевые домены

Расширение работает исключительно на перечисленных FQDN. Можно указать полный URL — из него будет взят только host. Путь ограничивает работу конкретным разделом сайта.

Модули

Каждый модуль автономен. Тумблер выключает модуль полностью: его content-скрипты перестают регистрироваться.

Добавление модулей

Модуль — это папка в modules/ с манифестом module.json, зарегистрированная в modules/registry.json.

Как добавить новый модуль
  1. Создайте папку modules/<id>/.
  2. Опишите модуль в module.json: имя, файлы, настройки по умолчанию и схему настроек.
  3. Добавьте <id> в массив modules файла modules/registry.json.
  4. Перезагрузите расширение на странице chrome://extensions.

Пример module.json:

{
  "id": "my-module",
  "name": "Мой модуль",
  "description": "Что делает модуль",
  "defaultEnabled": true,
  "runAt": "document_idle",
  "files": {
    "js": ["modules/my-module/content.js"],
    "css": []
  },
  "settings": { "someOption": true },
  "settingsSchema": [
    { "key": "someOption", "type": "boolean", "label": "Опция" }
  ]
}

Подробности — в docs/ADDING_MODULES.md репозитория.
